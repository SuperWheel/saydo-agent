## 3. 真实模型回归集

### 3.1 运行方式

```bash
make eval-llm
```

脚本 `apps/api/scripts/llm_eval.py` 用 `.env` 里配置的模型，在临时数据库上逐条运行 `apps/api/evals/regression.yaml`，每条用例前重置演示数据。

- **意图准确率**：最后一句调用的工具命中 `tool` 的比例（`none` 表示不该调工具）。
- **任务成功率**：最后一句出现的卡片命中 `card` 的比例（例如 `confirm/RED`、`clarify`）。
- 意图准确率低于 90% 时退出码为 1。
- 只跑一类：`cd apps/api && uv run python scripts/llm_eval.py transfer-`。

> 这条命令会调用付费模型，每跑一遍 152 条约 25–30 分钟（按 10.6 秒 / 条估算）。

### 5.4 端到端测试（Playwright，规则模式）

```bash
cd apps/web && npx playwright install chromium   # 首次运行，下载浏览器
make e2e                                          # 或 cd apps/web && npm run e2e
```

- 用例在 `apps/web/e2e/demo.spec.js`，配置在 `apps/web/playwright.config.js`。
- 测试自己起一套前后端：后端 `127.0.0.1:8765`、前端 `127.0.0.1:5174`，不占 `make dev` 的 8000 / 5173，开着 `make dev` 也能跑。

- 失败时在 `apps/web/test-results/` 留截图和 trace（`npx playwright show-trace <trace.zip>` 查看）。
