## 0. 录制前准备

| # | 事项 | 做法 |
|---|---|---|
| 1 | 启动 | `DEMO_DATE=2026-10-30 make dev`（下文的日期和金额都是按 10-30 这天核对的；不设的话按真实日期生成数据，生日、快进时间、账单数字都会变），浏览器打开 http://127.0.0.1:5173 ，窗口调成手机宽度（页面最大宽 430px）。手机和电脑连同一网络时，手机打开启动日志里 `Network:` 那行的地址也能用 |

| 3 | 重置数据 | 右上角「运营后台」→ 输入口令（设了 `ADMIN_PASSWORD` 时弹出「运营后台口令」框，同一标签页只输一次）→「重置演示数据」。**每次录制前都要重置**：转账会占用当日额度，注入快捷语点过 3 次会触发转人工。重置后页面回到人脸页（之前的进入凭证作废），正好从开场的人脸页开始录 |
| 4 | 快捷语 | 输入框上方的快捷语可以横向滑动。下文标「快捷语」的直接点，标「输入」的手动打字 |
| 5 | 节奏 | 固定流程走确定性工作流，即时返回；需要模型理解的轮次约 10 秒，录制时可以剪掉等待气泡（显示「正在理解你的意思…」和已等待秒数）。气泡下方标签写着这一轮是「确定性工作流」还是「AI 生成」以及用了几秒，剪辑时别裁掉 |

## 7. 常见状况

| 状况 | 原因 | 处理 |
|---|---|---|
| 「给我妈转500」一开始就是 🔴 | 没重置数据，当日已有转出 | 重置演示数据后重录 |
| 录到一半回到了人脸页 | 进入凭证 30 分钟到期，或在别的标签页重置了演示数据 | 点「开始验证」，聊天记录还在，接着录；长时间录制前先重置一次，从人脸页重新开始 |
| 打开就是聊天页、没有人脸页 | 同一标签页 30 分钟内已经验证过（刷新不用重验） | 重置演示数据，或关掉标签页重新打开 |
| 所有资金操作都提示「安全保护已开启」 | 之前点过 3 次注入快捷语 | 熔断卡上「联系人工客服」核实解除，或运营后台「熔断与风险」→「人工解除」，或重置数据 |
| 计划卡上没有「快进」按钮 | 心愿罐那张确认卡还没确认 | 先确认存入心愿罐 |
| 「上个月有没有异常消费」说没有异常 | 没有先做时间快进，「上个月」还是 9 月 | 按脚本顺序录；或改问「这个月有没有异常消费」 |
| 回复标签是「系统回复」而不是「AI 生成」 | 这一轮模型超时、报错，或模型文字没通过校验，系统换成了模板句 | 不影响卡片，继续录；剪辑时可保留，说明降级机制 |
| 智谱在攻击段返回 400 | 智谱内容审核拒绝了注入句子 | 系统会走规则 / 模板，卡片和熔断照常；用 DeepSeek 录制可避免 |
| 等待气泡超过 15 秒 | 模型慢 | 剪掉等待；或改用规则模式录 |
| 「我还有多少钱」的标签不是「确定性工作流」 | 录对比片段时关掉的开关没打开 | 「设置」→「模型」打开「确定性工作流」，保存 |

## 8. 与 PRD 草案的差异

| PRD §11.2 草案 | 本脚本 | 原因 |
|---|---|---|
| 「我还有多少钱？这个月钱怎么花这么快？」一句话问两件事 | 拆成「我还有多少钱」「上个月的账单报告」两句 | 每句一张卡，规则模式也稳定；「上个月」有完整一个月的数据 |
| 「下个月 20 号我爱人生日」 | 「下周五我妈生日，帮我订束花和蛋糕，再存 500 进心愿罐」 | 和前端快捷语一致；一句话里包含存钱、订花、订蛋糕三类动作，计划卡更完整 |
| 心愿罐预留 1000 | 存 500 | 与快捷语一致 |
| 「蛋糕不要了」→ 重新规划；「撤销刚才的锁定」→ 回退 | 「蛋糕不要了」放在快进之前；「撤销锁定」放在鲜花下单之后 | 计划卡上两种变化都能看到，且每一步都只需点一次确认 |
| 4:20–5:00 飞书里查余额，🔴 跳转 App | 删除，换成订阅取消（1:30–2:10） | 渠道改为企业微信（已实现，需真实 BotID / Secret 联调）；联调通过前不放进 5 分钟主线，答辩可现场补演 |
| 攻击段：转账备注藏注入，让 Agent 分析账单 | 用「上个月有没有异常消费」 | 规则模式和真实模型都会读到含注入备注的 10 月流水 |
| 运营后台回放 | 回放 + 校验哈希链 + 熔断人工解除 | 补上人工干预的得分点 |
