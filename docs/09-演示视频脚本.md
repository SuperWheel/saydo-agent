### 备选片段：知识问答（约 40 秒，真实模型）

可替换主线中的其他等长镜头，或答辩时现场演示，不追加到 5 分钟成片。录之前在「设置」→「知识检索」确认三张卡片都开着：向量检索（`Qwen/Qwen3-Embedding-8B`）、重排模型（`Qwen/Qwen3-Reranker-4B` · 门槛 0.525）、没查到时换说法重查（开关打开）。顶部写着「当前：关键词 + 向量检索 → 重排 → 没查到时换说法重查」。`.env` 要配 `EMBEDDING_PROVIDER=siliconflow`、`RERANK_PROVIDER=siliconflow` 和对话模型；规则模式只用关键词检索、不改写。

| 时间 | 口播 | 操作 / 输入 | 预期画面 |
|---|---|---|---|
| +0:00 | 问规则类问题，答案只来自知识库，每条都带出处。 | 输入「锁卡和挂失有什么区别」 | 知识卡「知识问答」：第一条「锁卡和挂失的区别」，后面是「银行卡丢了怎么办」「发现银行卡被盗刷怎么办」；每条下面有出处「演示知识库 · 本行（演示）业务规则 · 常见问题 · …… · kb-2026-10b · 2026-10-31 生效」；标签「AI 生成 · 约 10 秒」 |
| +0:10 | 检索分三步：关键词加向量找候选，重排模型逐条打分把关；原话没查到，再让模型换成条文的书面说法查一次。 | 打开「设置」→「知识检索」 | 三张卡片：向量检索「向量 + 关键词混合检索」、重排模型「已启用重排」、没查到时换说法重查（开关打开，标「可选」「agentic」） |
| +0:20 | 换说法重查会多等两秒左右，但只发生在原话没查到的时候。我们比较过：知识库答错的代价比慢两秒大，用不多的耗时换更可靠的答案，所以默认打开。 | 停在设置页，右侧叠加字幕表 | 字幕表「168 道换说法难题 · 正确率」：纯关键词 65.5% → 关键词 + 向量 75.6% → 加 4B 重排 97.0%；底部小字「换说法重查：约 22% 的问题触发，每次中位多 2.2 秒」 |
| +0:32 | 换了说法也查不到的，如实说没查到，不靠常识编。 | 关掉设置，输入「公积金贷款最多能贷多少」 | 提示卡「演示知识库里没有查到相关规定，我不能凭常识回答。可以换个说法再问，或者说「转人工」咨询客服。」；标签「系统回复 · 约 6 秒」（多出来的是模型判断要不要换说法，它判断不在知识库范围，没有改写） |

> 字幕表数字来自 [测试报告 §3.7](06-测试报告.md#37-知识问答评测ws9) 的 168 题对比（11-01）。2026-11-01 用 `glm-5.3-flash` 在预览环境逐句核对过：「锁卡和挂失有什么区别」出 3 条知识卡；「公积金贷款最多能贷多少」先查原话没查到，改写那一步模型回「无」，审计 `kb_query_rewrite` 里 `rewrites` 为空，最后如实说没查到。
>
> 原话没查到、按改写查到时，知识卡顶部会多一行灰底小字「原话没查到，换个说法查：「……」」。真实模型调知识库时常常自己先换好说法（核对时把「帮我查一下规定：别人借我身份证办卡有没有风险」换成「出借身份证办卡有什么风险」，一次就查到），所以这一行不是每次都有，不把它当成必出画面。只测检索时，「别人借我身份证办卡有没有风险」原话没查到，改写成「将身份证借给他人办理银行卡存在哪些风险」后查到「不能出租、出借、买卖银行卡和账户」。

## 7. 常见状况

| 状况 | 原因 | 处理 |
|---|---|---|
| 第一次付款没有协议卡 | 预签开关为 `true`，或已签过协议 | 保持默认 `false` 后重置数据，或用 `POST /dev/payment-agreement/reset` 撤回；正式录制先清零累计 |
| 「给我妈转500」一开始就是 🔴 | 没重置数据，当日已有转出 | 重置演示数据后重录 |
| 妹妹 800 元仍是 🔴 | 免密未开通、额度设置不同、亲密关系未验证，或已触发频繁转账等规则 | 检查授权默认卡、2,000 / 5,000 元额度和关系；重置后按主线顺序重录，额外风险不豁免 |
| 录到一半回到了人脸页 | 进入凭证 30 分钟到期，或在别的标签页重置了演示数据 | 点「开始验证」，聊天记录还在，接着录；长时间录制前先重置一次，从人脸页重新开始 |
| 打开就是聊天页、没有人脸页 | 同一标签页 30 分钟内已经验证过（刷新不用重验） | 重置演示数据，或关掉标签页重新打开 |
| 所有资金操作都提示「安全保护已开启」 | 之前点过 3 次注入快捷语 | 熔断卡上「联系人工客服」核实解除，或运营后台「熔断与风险」→「人工解除」，或重置数据 |
| 计划卡上没有「快进」按钮 | 心愿罐那张确认卡还没确认 | 先确认存入心愿罐 |
| 「上个月有没有异常消费」说没有异常 | 没有先做时间快进，「上个月」还是 9 月 | 按脚本顺序录；或改问「这个月有没有异常消费」 |
| 回复标签是「系统回复」而不是「AI 生成」 | 这一轮模型超时、报错，或模型文字没通过校验，系统换成了模板句 | 不影响卡片，继续录；剪辑时可保留，说明降级机制 |
| 智谱在攻击段返回 400 | 智谱内容审核拒绝了注入句子 | 系统会走规则 / 模板，卡片和熔断照常；用 DeepSeek 录制可避免 |
| 等待气泡超过 15 秒 | 模型慢 | 剪掉等待；或改用规则模式录 |
| 问规则类问题，模型直接回答、没有知识卡 | 模型这一轮没调知识库（真实模型偶发，口语化的问法更常见） | 重问一次，或者在问题前加「帮我查一下规定：」 |
| 知识卡上没有「原话没查到，换个说法查」 | 模型调知识库时自己已经换好了说法、一次就查到，用不上重查；或者在规则模式下（不改写） | 正常，答案不受影响；重查的效果用字幕表说明 |
| 「我还有多少钱」的标签不是「确定性工作流」 | 录对比片段时关掉的开关没打开 | 「设置」→「模型」打开「确定性工作流」，保存 |

## 8. 与 PRD 草案的差异

| PRD §11.2 草案 | 本脚本 | 原因 |
|---|---|---|
| 「我还有多少钱？这个月钱怎么花这么快？」一句话问两件事 | 拆成「我还有多少钱」「上个月的账单报告」两句 | 每句一张卡，规则模式也稳定；「上个月」有完整一个月的数据 |
| 「下个月 20 号我爱人生日」 | 「下周五我妈生日，帮我订束花和蛋糕，再存 500 进心愿罐」 | 和前端快捷语一致；一句话里包含存钱、订花、订蛋糕三类动作，计划卡更完整 |
| 心愿罐预留 1000 | 存 500 | 与快捷语一致 |
| 「蛋糕不要了」→ 重新规划；「撤销刚才的锁定」→ 回退 | 「蛋糕不要了」放在快进之前；「撤销锁定」放在鲜花下单之后 | 计划卡上两种变化都能看到，且每一步都只需点一次确认 |
| 4:20–5:00 飞书里查余额，🔴 跳转 App | 删除，换成订阅取消（1:55–2:20） | 渠道改为企业微信（已实现，需真实 BotID / Secret 联调）；联调通过前不放进 5 分钟主线，答辩可现场补演 |
| 攻击段：转账备注藏注入，让 Agent 分析账单 | 用「上个月有没有异常消费」 | 规则模式和真实模型都会读到含注入备注的 10 月流水 |
| 转账只展示累计超额 | 首次签协议 → 开通免密 → 额度内确认 → 超单笔升 🔴 | 展示比赛版本的支付与联系人亮点；压缩开场、订阅和生日段，保持 5:00 |
| 运营后台回放 | 回放 + 校验哈希链 + 熔断人工解除 | 补上人工干预的得分点 |
