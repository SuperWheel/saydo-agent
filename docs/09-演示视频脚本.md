## 备用与排障

| 状况 | 处理 |
|---|---|
| 断网 / 模型不可用 | 事先用独立规则实例录制同一主线，画面明确「规则模式」。本片无需自由分析、在线向量、重排或改写，不声称演示了模型泛化 |
| 真实模型等待较长 | 保留等待气泡及实际秒数；跳剪加字幕，不伪装即时响应。模型轮次历史均值 8.2 秒、自由分析约 18 秒，详见测试报告 |
| 第一次转账没有协议卡 | 确认独立实例未签协议、已关闭预签；只重置自己的隔离实例。不要重置在线演示库 |
| 妹妹 800 仍升 🔴 | 核对本人设定的 2,000 / 5,000 额度、卡 6688、有效亲密关系及无额外转账；风险不豁免，不能强行降黄 |
| 免密表单预览日期不同 | 前端按浏览器日期预览，服务端按演示日期确认；标「待录制时核对」，以真实确认卡为准，交代码任务核查，不在本次修改前端 |
| 按摩椅到期要求验证 | 排查误点预算锁定改成罐付、免密授权失效或到期风险变化。保留真实结果；不接上别次自动回执 |
| 没有快进按钮 | 生日存罐尚未验证或未同步计划；先办完再看最新计划卡。旧计划卡不作为入口 |
| 异常查询没有 10 月两笔 | 当前日期不对；本片应先快进至 11-05，再问「上个月」。不混用初始 10-30 的查询画面 |
| 进入凭证失效 | 重新核身；若只是凭证过期，不重置数据和时钟 |
| 熔断后还想展示更多付款 | 不继续点资金快捷语；先模拟人工核实解除。本片不再增加一笔转账，避免改变余额与节奏 |
| 全片超过 5 分钟 | 先缩打字、重复滚轮和后台切换；保留授权、风险原因和回执。不得为了速度删掉两因子或生日订单确认造成流程误导 |
